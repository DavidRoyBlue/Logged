# Architecture Decision Records

> Index of durable architectural decisions. Rules for writing ADRs live in [`./CLAUDE.md`](./CLAUDE.md).
> The template is [`./ADR-000-template.md`](./ADR-000-template.md).

An ADR records *what* was decided and *why*, for decisions that constrain future
choices or are expensive to reverse. Numbers are global, zero-padded to 3 digits,
never reused.
